## 1. サービス概要

**ラクシフトAI** は、飲食・小売・医療介護店舗向けのAIシフト自動生成SaaS。

- **Python数理最適化(PuLP/MILP)** でベースシフトを生成（3段階フォールバック）
- **Gemini AI** が労働基準法チェック・最終監査
- **プレビュー機能** で生成結果を確認してから保存
- マルチテナント対応（1契約ID = 1店舗）
- Stripe決済によるサブスクリプション課金

**URL:**
- 本体: https://rakushift-ai.pages.dev
- 管理画面: https://rakushift-ai.pages.dev/admin
- GitHub: https://github.com/mochikuro00/rakushift-ai

## 10. AIシフト生成の仕組み

### フロー（プレビュー対応版）
```
「AIシフト作成」ボタン → 作成範囲選択
  ↓
1. /check — 人員充足チェック
  ↓
2. /generate — PuLP MILP最適化 → Gemini AI監査
  ↓
3. ★プレビューモーダル表示（統計サマリー＋日別シフト表）
  ↓
4. ユーザーが「確定して保存」→ DB保存
  ↓
5. AI診断（バックグラウンド実行）
```

### 制約（3段階フォールバック）

**Tier 1: 法定（絶対遵守）**
- 1日8時間以内 / 週40時間以内（労基法32条）
- 6h超→45分休憩、8h超→60分休憩（労基法34条）
- 連続6日まで、週1日休日（労基法35条）

**Tier 2: 店舗ルール**
- 最低人員、管理者常駐、定休日

**Tier 3: 高度な制約（ソフト制約）**
- ポジション別（ホール・キッチン等）の必要人数確保
- 人間関係の相性制約（NGペア・必須ペア）

**Tier 4: 最適化**
- チーム戦力バランス、新人メンター、コスト最小化
- 本人希望時間の優先（希望時間考慮トグルONのスタッフのみ）

**解けない場合（Infeasible時）のフェイルセーフ:** 
Tier4緩和 → Tier3緩和 → 貪欲法（Greedy）フォールバック
※それでも不足する場合は `is_irregular=True` をセットして強制配置し、UIで赤枠警告（Human-in-the-loop設計）。

## 11. Stripe決済フロー

```
申込フォーム → /stripe/new-subscription → Stripe決済
  ↓ Webhook (checkout.session.completed)
テナント自動作成 → config更新
  ↓ 運営が管理画面で確認
「案内送信」→ ウェルカムメール（契約ID・パスワード）
```

### 決済失敗時
1. `invoice.payment_failed` → `past_due` 状態
2. 顧客画面にオレンジバナー + 再決済ボタン
3. 21日間未対応 → 自動ライセンス停止

## 16. デプロイ手順

### フロントエンド（Cloudflare Pages）
- GitHubにpush → 自動デプロイ

### バックエンド（Railway）
- GitHubにpush → Dockerfileで自動ビルド＆デプロイ
- Root Directory: `/`（ルート）
- Builder: Dockerfile（`python/Dockerfile`）
- 環境変数: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `ADMIN_API_TOKEN`, `MIGRATION_TOKEN`

### データベース（Supabase）
- SQL Editorで `supabase/migrations/` 内のSQLを順番に実行

## 17. 運用ルール

### 役職と評価
| 役職 | シフト生成への影響 |
|------|----------------|
| Manager | 毎営業日に最低1名配置必須、メンター役 |
| Leader | メンター役（Managerと同等） |
| Staff | 通常配置 |
| Rookie | メンター必須（単独配置不可） |

### パスワード忘れ対応
- **マスターパスワード（`rakushift1234`）** で常にログイン可能
- SQL直接リセットも可能
