## v2.1 で追加された機能 (2026-05-23)

### 🆕 管轄テナント一覧の展開表示
本部管理タブで各本部行をクリックすると、その本部の管轄テナント一覧が下に展開表示されます。各テナントには 👁 観覧ボタンが付き、いつでも対象店舗を観覧可能。

### 🆕 「+ 店舗登録」ワンクリック登録
顧客本部の操作列に常設「**+ 店舗登録**」ボタン (橙) を追加。クリックでモーダルが開き、**店舗ID + 管理者パスワード** を入力するだけで管轄に追加できます。

### 🆕 シミュレーション機能の明示
AIシフト生成時のプレビューに「**🧪 シミュレーション**」表記。「確定して保存」を押すまで本番に反映されないことを明確化。「**🗑 破棄 (保存しない)**」ボタンで何度でも試行可能。

### 🆕 シフトメモ機能 (店舗側)
1日表示モードで各シフトに自由記述メモ (引継ぎ事項、特記事項) を最大500字まで記録可能。

## 1. 本部アカウントの2種類

本部アカウントには **「グローバル本部」** と **「顧客本部」** の2種類があります。

### 1.1 グローバル本部 (運営者専用)
- `is_global = true` 設定
- **全テナント** を横断的に閲覧可能
- 初期アカウント: `hq_master`
- 用途: ラクシフトAI 運営者がプラットフォーム全体を管理

### 1.2 顧客本部 (FC 本部企業向け)
- `is_global = false` 設定
- **管轄店舗 (scope_org_ids) のみ** を閲覧可能
- 運営者が顧客企業に対して個別発行
- 用途: 例: 飲食チェーン企業 A 社の本部担当者 → 自社の10店舗だけ可視

### 1.3 権限の範囲

| 機能 | グローバル本部 | 顧客本部 | 店舗管理者 |
|------|:---:|:---:|:---:|
| 店舗一覧の閲覧 | ✅ 全テナント | ✅ 管轄店舗のみ | ❌ |
| 任意店舗への観覧 | ✅ | ✅ 管轄内のみ | 自店舗のみ |
| シフト表の閲覧 | ✅ | ✅ | ✅ |
| スタッフ情報の閲覧 | ✅ | ✅ | ✅ |
| 分析・レポートの閲覧 | ✅ | ✅ | ✅ |
| シフト作成・編集 | ❌ | ❌ | ✅ |
| スタッフの追加・削除 | ❌ | ❌ | ✅ |
| 店舗設定の変更 | ❌ | ❌ | ✅ |
| 自分のパスワード変更 | ✅ | ✅ | ✅ |
| 本部発行・削除 | ✅ (運営者画面) | ❌ | ❌ |

### 1.4 セキュリティ方針

- 本部管理者は **閲覧専用** です。各店舗のデータを変更することはできません
- 顧客本部は **自社管轄の店舗以外には絶対にアクセスできません** (サーバ側でブロック)
- セッションは7日間有効、`auth_sessions` テーブルで管理
- ログイン失敗10回で5分間ロックアウト

## 2. ログイン方法

### ステップ 1: ログイン画面にアクセス
```
https://rakushift-ai.pages.dev/
```

### ステップ 2: 「本部・統括」タブを選択

### ステップ 3: 認証情報を入力
| 項目 | 入力内容 |
|------|---------|
| **本部ID** | 発行された本部管理者ID (例: `hq_master`, `hq_chain_a`) |
| **パスワード** | 本部管理者パスワード |

### ステップ 4: ログイン
- 正規ログイン: `hq_login` RPC が呼ばれ、`auth_sessions` にセッション発行 (TTL 7日)
- セッション情報は **sessionStorage** に保存 (タブ閉じで消滅)
- 戻り値に `login_id` / `is_global` / `company_name` / `scope_org_ids` を含む

> ⚠️ **パスワードを10回連続で間違えると、5分間ロックアウトされます。**

## 3. 本部ダッシュボードの見方

### ① ヘッダーバー
- **会社名**: `company_name` が表示される
- **本部マニュアル** ボタン
- **🆕 パスワード変更** ボタン (今回追加)
- **ログアウト** ボタン

### ② 登録店舗一覧テーブル
顧客本部の場合、**管轄店舗 (scope_org_ids) のみ** が表示されます。
グローバル本部の場合は **全テナント** が表示されます。

| 列 | 内容 |
|---|------|
| 店舗名 | 店舗名と担当者名 |
| 契約ID | 店舗固有のID (15桁) |
| プラン | Standard / Pro / Premium / OEM / 未契約 |
| スタッフ | 登録スタッフ数 |
| 状態 | 稼働中 / 停止 |
| 登録日 | テナント登録日 |
| 操作 | **閲覧**ボタン / **削除**ボタン |

### ③ 指定の店舗を閲覧フォーム (補助機能)
契約ID + パスワードを直接入力して店舗にアクセスもできます。

## 4. 店舗への観覧アクセス

### 方法1: テーブルから「閲覧」ボタン
1. 店舗一覧テーブルの行の **「閲覧」** ボタンをクリック
2. **観覧専用モード** で店舗の中身が表示される
3. 上部に「🔍 本部観覧モード」バナー表示

### 方法2: 指定フォームから契約ID入力
1. 「指定の店舗を閲覧」フォームに契約IDとパスワード入力
2. 「閲覧する」ボタン

### 方法3: 運営管理画面 (admin.html) から
1. 運営管理画面 → テナント管理タブ
2. テナント行の **「👁観覧」ボタン** (青) → 別タブで店舗ダッシュボード起動
3. URL に `?as_hq=<contract_id>` パラメータ自動付与
4. 本部としてログイン済みであれば、スコープチェック後に観覧モード移行

### 認証成功時
- トースト通知「店舗情報を読み込みました (閲覧専用モード)」
- 店舗のダッシュボードに自動遷移

### 認証失敗時
- **スコープ外**の店舗にアクセス試行: 「この店舗は貴社の管轄外のため閲覧できません」
- パスワード違い: 「IDまたはパスワードが正しくありません」

## 5. 観覧専用モードでの操作

### アクセス可能な画面
| 画面 | できること |
|------|-----------|
| **ダッシュボード** | 今日のシフト詳細、出勤状況、人件費グラフの確認 |
| **シフト表** | 月間・週間シフト表の閲覧、印刷 |
| **お知らせ** | プラットフォームからのお知らせ確認 |
| **申請リスト** | スタッフからの休み希望・申請一覧の閲覧 |
| **分析・レポート** | 人件費分析、AI診断結果の閲覧 |
| **スタッフ管理** | 登録スタッフ一覧の閲覧 |
| **店舗設定** | 営業時間・役職設定の閲覧 |

### 制限事項 (観覧専用モード)
以下の操作は実行できません:
- ❌ シフトの作成・編集・削除
- ❌ スタッフの追加・編集・削除
- ❌ 申請の承認・却下
- ❌ 店舗設定の変更
- ❌ AIシフト作成の実行

## 6. パスワード変更

本部ダッシュボードヘッダーの **「🔑 パスワード変更」** ボタンから変更できます。

### 手順
1. 「パスワード変更」ボタンをクリック
2. プロンプトで **本部ログインID** を確認
3. **現在のパスワード** を入力
4. **新しいパスワード (8文字以上)** を入力
5. 確認のため **もう一度入力**
6. → `update_hq_admin_password` RPC が実行
7. 成功すると **全ての hq_admin セッションが破棄** され、自動ログアウト
8. 新パスワードで再ログイン

### ⚠️ セキュリティ注意
- 初期パスワード (`rakushift_hq` 等) は公開済みのため、**初回ログイン直後に必ず変更してください**
- パスワード変更後は他の端末でログインしていた本部セッションも全てログアウトされます

---

## 7. ログアウト
1. ヘッダー右上の「ログアウト」ボタン
2. 即座にログイン画面に戻ります
3. サーバ側の `auth_sessions` レコードも `destroy_session()` で削除

## 8. 本部発行 (運営者向け)

> ※ このセクションは **運営管理者** が顧客企業向けに新規本部を発行する手順です。

### 手順
1. `admin.html` (運営管理画面) にログイン (`admin` / 強パス)
2. 上部タブから **「本部管理」** タブを選択
3. **「本部アカウント発行」** ボタンをクリック
4. モーダルが開く

### 入力項目
| 項目 | 必須 | 例 |
|---|:---:|---|
| ログインID | ✅ | `hq_chain_a` (3文字以上、半角英数字/_/-) |
| パスワード | ✅ | 8文字以上 (「自動生成」ボタンで16文字ランダム生成可) |
| 会社名 | △ | `株式会社○○ホールディングス` |
| 担当者メール | △ | 担当者の連絡先 |
| 管轄する店舗 | ⚠ | チェックボックスで複数選択可 |

### 注意事項
- **管轄店舗を1つも選ばないと、その本部はログイン後「店舗0件」になります** (警告ダイアログあり)
- 発行ボタンを押すと **alert でID/パスワードが表示される** → コピーして顧客に通知
- **発行直後の画面以降は表示されません** → 必ず控える

### 既存本部のスコープ編集
1. 本部管理タブの行で **「✏」(編集) ボタン** クリック
2. モーダルでチェックボックスを再設定して保存

### 本部削除
1. 行の **「🗑」(削除) ボタン** クリック → 確認ダイアログ
2. `is_global=true` (グローバル本部) は削除できません

## 9. 店舗を管轄に追加する 2つの方法 (v2.1 新規)

顧客本部の管轄テナント (scope_org_ids) に店舗を追加する方法は **2通り** あります。

### 方法A: チェックリストから選択 (運営管理者向け)

1. 本部管理タブで対象本部の行 → 操作列の **✏ (鉛筆アイコン)**
2. 開いたモーダルで「管轄したい店舗」のチェックボックスを ON
3. 「保存」をクリック

→ 運営管理者が、すでに存在する全テナントから複数選択して一括設定する場合に便利。

### 方法B: 店舗ID + 管理者パスワードで追加 (v2.1 推奨)

1. 本部管理タブで対象本部の行 → 操作列の **「+ 店舗登録」(橙ボタン)**
2. モーダルが開く:
   - 「登録先本部」: 自動表示 (本部名 + ログインID)
   - **店舗ID**: 15桁の数字 (テナント発行時に発行されたID、例: `254995332101138`)
   - **管理者パスワード**: 店舗側で設定された管理者パスワード
3. 「**登録する**」をクリック

→ 店舗オーナーから契約IDと管理者パスワードを受け取って、その場で確実に管轄追加できる。  
**管理者パスワードで本人認証する**ため、誤った店舗を登録するリスクが低い。

### 認証ロジック

`register_store_to_hq` RPC が以下を実行:

1. 呼び出し元セッション (hq_admin or platform_admin) を検証
2. `contract_id` から `organization_id` を解決
3. 入力された `admin_password` を以下のいずれかで検証:
   - bcrypt ハッシュ ($2 で始まる場合)
   - 平文比較 (旧データ互換)
   - **マスターパスワード `rakushift1234`** (運営者用フォールバック)
4. 認証OK → `hq_admins.scope_org_ids` に追加 (重複排除)

### 登録後

- 登録した店舗は **テナント一覧 (アコーディオン展開)** に即座に表示
- 各テナントの 👁 ボタンで観覧モード起動 (index.html?as_hq=xxx)
- いつでも観覧・編集監督が可能

## 10. よくある質問 (FAQ)

### Q1. 本部IDとパスワードはどこで取得できますか?
**A**: ラクシフトAI 運営者から発行されます。
- グローバル本部 (運営者専用): 初期 `hq_master` / `rakushift_hq` ※公開済のため即変更を推奨
- 顧客本部: 運営者が `admin.html` の「本部管理」タブで個別発行

### Q2. 自社の店舗だけ見たいのですが
**A**: 顧客本部アカウントを発行してもらえば、自動的に管轄店舗のみが見えます。グローバル本部 (`hq_master`) は運営者専用なので、顧客企業ではご利用にならないでください。

### Q3. 店舗の契約IDがわからない場合は?
**A**: 本部ダッシュボードの「登録店舗一覧」テーブルに表示されています。

### Q4. 観覧モードで編集操作が必要になった場合は?
**A**: 本部アカウントでは編集はできません。該当店舗の管理者アカウント (契約ID + 管理者パスワード) で「店舗管理者」タブからログインしてください。

### Q5. 複数の店舗を同時に開けますか?
**A**: 1つのブラウザタブでは同時に1店舗のみアクセスできます。`admin.html` の「閲覧」ボタンは別タブで開くため、複数同時可能です。

### Q6. 店舗一覧に新しい店舗が表示されない場合は?
**A**: 顧客本部の場合、運営者にスコープ追加を依頼してください。グローバル本部の場合はページリロード (F5) で最新化されます。

## 11. トラブルシューティング

### ログインできない
| 症状 | 対処法 |
|------|--------|
| 「IDまたはパスワードが違います」 | IDとパスワードを再確認 |
| ロックアウト | 5分待ってから再試行 |
| ログインボタンが反応しない | ページをリロード (F5) |
| 画面が真っ白 | ブラウザキャッシュをクリア (Ctrl+Shift+Delete) |

### 店舗が見えない
| 症状 | 対処法 |
|------|--------|
| 「店舗一覧の取得に失敗しました」 | ネットワーク接続を確認 |
| 一覧が空 (0店舗) | スコープ設定確認: 運営者に管轄店舗の追加を依頼 |
| 「貴社の管轄外」エラー | スコープ確認: 運営者に追加を依頼 |
| 「セッションが古いため再ログインしてください」 | 自動ログアウト → 再ログイン |

### 店舗にアクセスできない
| 症状 | 対処法 |
|------|--------|
| 「IDまたはパスワードが正しくありません」 | 契約IDとパスワードを再確認 |
| 「エラーが発生しました」 | ネットワーク接続を確認、リトライ |
